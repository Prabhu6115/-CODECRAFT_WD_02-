Tic-Tac-Toe Web Application

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. This project allows two players to compete against each other or play against a basic AI opponent. The application handles user input, maintains the game state, and checks for winning conditions in real-time.

Features

Two-player mode

Option to play against a basic AI

Visual indicator for the winner or a draw

Responsive and intuitive UI

Clean and minimalistic design


Technologies Used

HTML for structure

CSS for styling

JavaScript for game logic

How to Run

1. Clone the repository
2. Open index.html in your browser
3. Start playing!
